1. Define Unsupervised Learning. Explain how it differs from supervised learning.

Unsupervised Learning is a machine learning technique that analyzes unlabeled data to discover hidden patterns, structures, or relationships without predefined output labels. Its main objective is knowledge discovery rather than prediction. Major techniques include clustering and association rule learning.

Difference between Supervised and Unsupervised Learning
Aspect	Supervised Learning	Unsupervised Learning
Data Type	Labeled data	Unlabeled data
Objective	Predict output	Discover hidden structure
Output	Class or value	Groups or association rules
Examples	Classification, Regression	Clustering, Association

In supervised learning, the model learns from known outputs, whereas in unsupervised learning, the model identifies patterns automatically from the data.

2. Explain the main objectives of unsupervised learning.

The major objectives of unsupervised learning are:

Discover hidden patterns in unlabeled data.
Group similar data points using clustering techniques.
Identify relationships among variables using association rules.
Reduce data complexity through dimensionality reduction.
Detect anomalies or outliers in datasets.
Support decision making by extracting meaningful information from raw data.

Applications include customer segmentation, fraud detection, image processing, document clustering, and bioinformatics.

Importance of Clustering

Used in customer segmentation and recommendation systems.
Supports anomaly detection.
Useful in text mining, image processing, and market analysis.

Clustering improves understanding of unlabeled data and serves as a foundation for other machine learning techniques.

4. Explain the K-Means clustering algorithm with step-by-step procedure.

K-Means is a centroid-based partitioning clustering algorithm in which each cluster is represented by its centroid (mean point). The number of clusters K must be predefined.

Steps of K-Means Algorithm
Select K initial centroids randomly.
Assign each data point to the nearest centroid.
Recompute centroids by calculating the mean of points in each cluster.
Reassign data points to the updated centroids.
Repeat steps 3 and 4 until centroids stop changing significantly.
Output final clusters and centroids.
Advantages
Simple and fast.
Efficient for large datasets.
Limitations
Sensitive to outliers.
Requires predefined K.
Cannot handle non-spherical clusters effectively.

7. What is Association Rule Mining?

Example:

9. Describe the Apriori algorithm used for association rule mining.

Apriori is a popular algorithm used to generate frequent itemsets and association rules from transaction data. It follows a bottom-up approach.

Apriori Principle

If an itemset is frequent, all its subsets must also be frequent. If an itemset is infrequent, all its supersets are also infrequent.

Steps of Apriori Algorithm
Generate frequent 1-itemsets.
Generate candidate 2-itemsets from frequent 1-itemsets.
Prune infrequent itemsets using minimum support.
Repeat iteratively for k-itemsets.
Generate strong association rules using minimum confidence.
Advantages
Simple and effective.
Reduces search space using pruning.
Limitations
Requires multiple database scans.
Computationally expensive for large datasets.

14. Explain the McCulloch–Pitts neuron model. Discuss assumptions and limitations.

The McCulloch–Pitts neuron model was the first artificial neuron model proposed in 1943. It uses binary inputs and outputs with threshold logic.

Working
Inputs are multiplied by weights.
Weighted sum is calculated.
If the sum exceeds threshold, output becomes 1; otherwise 0.
Assumptions
Inputs are binary.
Outputs are binary.
Fixed threshold value.
No learning capability.
Limitations
Cannot learn from data.
Works only for simple logical operations.
Cannot solve complex non-linear problems.

20. Explain the Backpropagation algorithm used for training neural networks.

Backpropagation is a supervised learning algorithm used for training multi-layer feed-forward neural networks. It adjusts weights to minimize output error.

Phases of Backpropagation
1. Forward Pass
Inputs move from input layer to output layer.
Activation functions generate outputs.
2. Backward Pass
Output error is calculated.
Errors are propagated backward.
Weights are updated using gradient descent.
Steps
Initialize weights.
Perform forward propagation.
Compute output error.
Propagate error backward.
Update weights.
Repeat for multiple epochs.
Advantages
Learns complex non-linear relationships.
High accuracy.
Limitation
Computationally expensive for deep networks.

from sklearn.datasets import make_blobs

5. Find patterns using association rules.
transactions = [
 {"Bread", "Milk", "Egg"},
 {"Bread", "Milk"},
 {"Milk", "Egg"},
 {"Bread", "Egg"}
]

def support(itemset, transactions):
    return sum(1 for t in transactions if itemset.issubset(t)) / len(transactions)

def confidence(X, Y, transactions):
    return support(X.union(Y), transactions) / support(X, transactions)

print("Support(Bread):",
      support({"Bread"}, transactions))

print("Confidence(Bread -> Milk):",
      confidence({"Bread"}, {"Milk"}, transactions))

Association rules discover relationships between frequently occurring items.

from sklearn.neural_network import MLPClassifier
from sklearn.model_selection import train_test_split

    n_samples=300,

)

    max_iter=500
)

y_pred = model.predict(X_test)

print("Accuracy:", accuracy_score(y_test, y_pred))

9. Neural Network with one hidden layer using backpropagation.
import numpy as np

X = np.array([[0,0],[0,1],[1,0],[1,1]])
y = np.array([[0],[1],[1],[0]])

np.random.seed(1)

weights = np.random.rand(2,1)

learning_rate = 0.1

def sigmoid(x):
    return 1 / (1 + np.exp(-x))

def sigmoid_derivative(x):
    return x * (1 - x)

for epoch in range(5000):

    output = sigmoid(np.dot(X, weights))

    error = y - output

    adjustments = learning_rate * np.dot(
        X.T,
        error * sigmoid_derivative(output)
    )

    weights += adjustments

print("Final Output:")
print(output)
