1. What is representation learning? Explain its objective and applications.

Representation learning, also known as feature learning, is a type of machine learning in which the system automatically discovers useful features or representations from raw data using neural networks. It is mainly used when data is unstructured or unlabeled.

Objective:

The main objective of representation learning is to find an appropriate representation of data based on features in order to perform machine learning tasks efficiently. It reduces the need for manual feature engineering.

Working:
Input data is provided to the neural network.
Hidden layers automatically extract important features.
The learned features are used for classification or prediction.
Applications:
Speech recognition
Image recognition
Signal processing
Natural language processing
Music recognition
Conclusion:

Representation learning enables machines to automatically learn useful patterns from data and improves performance in complex machine learning tasks.

4. Define active learning. Explain its query strategies with examples.

Active learning is a semi-supervised learning method in which the learning algorithm interactively queries the user to obtain labels for selected data points.

Working:
Begin with small labeled data.
Train model.
Select most informative unlabeled samples.
Obtain labels and retrain model.
Query Strategies:
Uncertainty Sampling
Select data points where model confidence is minimum.
Query by Committee
Multiple models vote; samples with highest disagreement are selected.
Expected Model Change
Select samples that produce maximum change in model.
Expected Error Reduction
Select samples reducing future prediction error.
Variance Reduction
Select samples reducing output variance.
Example:

In medical diagnosis, the model asks experts to label uncertain patient records.

Conclusion:

Active learning minimizes labeling cost while improving model performance.

5. What is instance-based learning? Discuss its characteristics and give examples.

Instance-based learning is a memory-based learning approach in which new instances are compared with previously stored training examples rather than creating an explicit generalized model.

Characteristics:
Stores training instances directly in memory
Learning occurs during prediction time
Computational complexity increases with number of instances
Uses similarity measures such as Euclidean distance
Examples:
K-Nearest Neighbour (K-NN)
Support Vector Machine (SVM)
PCA
Radial Basis Function (RBF)
Conclusion:

Instance-based learning is effective for similarity-based classification problems.

Advantages:

AdaBoost.

Conclusion:

Ensemble learning improves prediction performance by combining multiple learners.

Transition Probability:

Example:

Conclusion:

Markov Chains model systems where future states depend only on present state.

3. Active Learning
import numpy as np
from sklearn.datasets import make_classification
from sklearn.linear_model import LogisticRegression

X, y = make_classification(
    n_samples=120,
    n_features=2,
    n_redundant=0,
    n_informative=2,
    random_state=0
)

labeled = np.arange(10)
unlabeled = np.arange(10, 120)

model = LogisticRegression(solver="liblinear")

for i in range(8):

    model.fit(X[labeled], y[labeled])

    probs = model.predict_proba(X[unlabeled])[:,1]

    query = np.argmin(np.abs(probs - 0.5))

    labeled = np.append(labeled, unlabeled[query])

    unlabeled = np.delete(unlabeled, query)

    print("Iteration:", i+1,
          "| Labeled Samples:", len(labeled))
4. Radial Basis Function (RBF)
import numpy as np

X = np.array([1,3,5])
centers = np.array([2,4])

sigma = 1

for x in X:
    for c in centers:

        distance = np.linalg.norm(x-c)

        rbf = np.exp(-(distance**2)/(2*sigma**2))

        print("Input:", x,
              "Center:", c,
              "Distance:", distance,
              "RBF:", round(rbf,4))
5. Apriori Algorithm
transactions = [
    {"A","B"},
    {"A","C"},
    {"B","C"},
    {"A","B","C"}
]

from itertools import combinations

items = sorted(set().union(*transactions))

def support(itemset):
    return sum(1 for t in transactions
               if itemset.issubset(t))

# Candidate 1-itemsets
C1 = [{i} for i in items]

print("Candidate 1-itemsets:")
for c in C1:
    print(c, support(c))

# Candidate 2-itemsets
C2 = [set(c) for c in combinations(items,2)]

print("\nCandidate 2-itemsets:")
for c in C2:
    print(c, support(c))

print("\nFrequent Itemsets:")
for c in C1 + C2:
    if support(c) >= 2:
        print(c)
6. ECLAT Algorithm
transactions = [
    {"A","B"},
    {"A","C"},
    {"B","C"}
]

min_sup = 2

tid = {}

for i, t in enumerate(transactions):

    for item in t:

        if item not in tid:
            tid[item] = set()

        tid[item].add(i)

print("TID Lists:", tid)

AB = tid["A"] & tid["B"]

print("Support of (A,B):", len(AB))

if len(AB) >= min_sup:
    print("(A,B) is Frequent")

20. Q-Learning
import numpy as np

states = [0,1,2]
actions = [0,1]

Q = np.zeros((3,2))

alpha = 0.1
gamma = 0.9

for ep in range(20):

    state = np.random.choice(states)

    action = np.random.choice(actions)

    next_state = np.random.choice(states)

    reward = np.random.randint(0,5)

    Q[state, action] += alpha * (
        reward +
        gamma * np.max(Q[next_state]) -
        Q[state, action]
    )

print("Final Q-Table:\n")
print(Q)
